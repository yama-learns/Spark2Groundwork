# corpus/ — put your source papers here

**Put every PDF you intend to cite in this folder.**

One file per paper. A filename like "FirstAuthor_Year_keyword.pdf" works well:

```
Chen_2023_working_memory.pdf
Lin_2021_bilingual_advantage.pdf
```

**Why it has to be here:** the framework checks whether the sentence you quoted
is actually in the source. If the source is not in the project, that check cannot
run — **and "could not check" is not the same as "no problem".**

---

## There is also a `BIBLIOGRAPHY.docx` in this folder

**It is this project's authority for citation formatting.**
Export your bibliography from Zotero or EndNote, paste it in, and from then on
every citation follows that file.

---

⚠️ **Nothing in this folder is ever touched when you upgrade the framework.**
⛔ **And nothing can restore it either** — keep your own backup.
