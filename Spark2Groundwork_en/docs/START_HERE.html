Start with a project check

No terminal commands are required. Extract the complete English folder, then double-click check_project.bat (Windows) or check_project.command (Mac) in its root. Read the results and press a key to close.

If a tool is missing

  1. Python: use the official download page and graphical installer for your system. Use the official pkg on Mac. On Windows, open the Windows releases page, choose a stable version supporting your system, then select Windows installer (64-bit) and Install Now. This uses the full installer; an install manager without an installed Python runtime is not ready yet. No manual PATH edits are needed; rerun the check after installation.
  2. Git: use the Windows installer. On Mac, sign in to Apple Downloads, choose the matching Command Line Tools for Xcode and install its dmg/pkg. The complete Xcode app and pasted commands are not required.

First opening on Mac is blocked

Verify the source first. Follow Apple's safe-opening instructions for the specific file. Do not disable protections for the whole folder. If no opening option exists or executable permission is missing, preserve and report the message; the check is incomplete. A native Mac test must validate the final downloaded package.

Read the result

  • PASS / 0: this mechanical check passed, not proof that research claims are true.
  • FAIL / 1: the checks found something to address.
  • INCOMPLETE / 2: missing tools/files or unfinished checks; never a PASS. Share the full output with your AI. A new download without a checkpoint needs the snapshot step in SETUP.
