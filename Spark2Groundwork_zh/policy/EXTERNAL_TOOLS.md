# 外部工具政策

**文件層級：T1 — 規格類。**
**完整操作見 `profiles/PROFILE_external_tools.md`；本檔只定不可違反者。**

---

1. ⛔ **外部工具的產出 ＝ 未驗證線索。未經原文查證不得引用其任何論述。**
2. ⛔ **外部 prompt 必須完全自足**，不得跨 prompt 指涉。
3. ⛔ **外部產出不得放進語料庫**——語料庫是程式化提取的原文，
   混入 AI 文本會使錨點查證變成比對 AI 自己寫的句子。
4. ⛔ **自動化流程不得直接寫入台帳。**
5. **兩個模型跑同一個 prompt 時，分歧處是最高價值的產物**——
   它指出了一個至少有一方錯的地方。
