# 情境設定：使用外部 AI 工具

**適用：** Deep Research、自動化流程（n8n／Zapier）、檢索代理、任何在你視線外執行的 AI。
**⚠️ 本份是附加，請與其他 profile 併用。**

---

## 1. 一條總規則

⛔ **外部工具的產出 ＝ 未驗證線索。它的唯一合法用途是「指出議題」。**

**⛔ 未經原文查證，不得引用其中任何論述、書目或數值。**

⚠️ **這不是保守。** 實測：兩個 Deep Research 模型對同一篇論文的轉述**皆錯，且錯在相反方向**；
而為調和兩者所提的解釋**也是錯的**——
**因為兩份轉述都不對，任何調和它們的假說都建立在假的資料上。**

## 2. 五級分流

收到外部報告後，逐條分類：

| 級 | 內容 | 處置 |
|---|---|---|
| **1** | 指出一個你不知道的主題／方法／爭議 | ✅ **最有價值。** 據此去找原文 |
| **2** | 給了具體書目 | ⚠️ 逐筆比對權威書目來源。**識別碼經常是錯的** |
| **3** | 給了數值 | ⛔ **一律回原文。** 未回原文前不得寫進任何文件 |
| **4** | 給了結論或判定 | ⛔ **一律視為未驗證** |
| **5** | 主題與你的問題無關 | 排除。**這是唯一的排除理由** |

⚠️ **兩個模型跑同一個 prompt，它們的「分歧處」是最高價值的產物**——
**分歧指出了一個至少有一方錯的地方，而那正是你該去查原文的地方。**

## 3. Prompt 必須自足

⛔ **每份外部 prompt 必須完全自足。不得寫「同上」「參見前述」「Same as R1」。**

⚠️ **理由：外部工具各次執行於獨立對話，彼此不共享上下文——
「同上」在執行端等同空白，被指涉的條款實質上不存在。**

**實測後果：** 某份 prompt 的 §1 引述了這條規則，**然後在下半部寫了「Same as R3-1」**。
被指涉的標記在該次執行中使用 **0 次**，而條款完整的那一份使用 **12 次**。
**引述規則與違反規則同處一檔。**

**查證方式：**

```
python3 scripts/harness/sensor_prompt_self_contained.py <你的prompt.md>
```

## 4. 自動化流程（n8n 等）的額外注意

| 風險 | 對策 |
|---|---|
| **無人看的中間產物** | 每個節點的輸出至少要落地成檔案，且**檔名帶時間戳** |
| **失敗被吞掉** | ⛔ 流程失敗時不得靜默重試。**須留下失敗紀錄** |
| **自動寫入台帳** | ⛔ **絕對禁止。** 台帳是「你確認過什麼」的紀錄 |

⚠️ **自動化最危險的一點：它會讓「沒有人看過」變成一個沒有痕跡的狀態。**
**本框架的整個設計前提，是讓「有沒有人看過」變成可查的事實。**

## 5. 外部工具的產出放哪裡

```
external/          ← 原始報告，只存不改
```

⛔ **不要把外部報告放進語料庫（`corpus_md/`）。**
語料庫是**程式化提取的原文**，是錨點比對的對象。
**混入 AI 產出的文本，會使錨點查證失去意義——你會比對到 AI 自己寫的句子。**
