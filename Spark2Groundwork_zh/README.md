# Spark2Groundwork（繁體中文版）

**把一個發想，變成一份站得住的研究提案。**

---

## 你只需要做三件事

| 做什麼 | 在哪 |
|---|---|
| **填一個檔案** | 根目錄 `PROJECT.md`——⛔ 其餘治理文件都由 AI 維護 |
| **按三個按鈕** | 記錄快照／查看變更／檢查更新（Windows `.bat`、macOS `.command`） |
| **裁決** | 你是唯一裁決者。AI 提請，你決定 |

⚠️ **框架資料夾可以整包從 GitHub 換新，⛔ 而你的台帳、語料、`PROJECT.md` 永遠不會被碰。**

---

## 0. 這是什麼

一套**檔案化的工作流治理框架**，讓你在與 AI 協作發展研究構想時，
能夠回答三個問題：

| 問題 | 誰回答 |
|---|---|
| **這句話的根據在哪一頁？** | 主張台帳 ＋ 錨點感測器 |
| **這個想法要怎樣才算被推翻？** | 猜想台帳 ＋ 反證條件欄 |
| **AI 剛才改了什麼？我看過了沒有？** | Git 檢查點 ＋ 兩支批次檔 |

⚠️ **這不是一套「讓 AI 更聰明」的東西。**
它假設 AI 會出錯，而且**會在最有把握的地方出錯**——
本框架的每一道防線，都對應一次真實發生過的失效。

---

## 1. 它不宣稱的事（**先讀這段**）

⛔ **本框架不保證你的研究是對的。** 它只保證：
**當它出錯時，錯誤留下痕跡，而不是靜靜地變成你的結論。**

| 它做得到 | 它做不到 |
|---|---|
| 查「這段話在不在原文裡」 | 查「原文是否支持你的推論」 |
| 查「反證條件欄有沒有填」 | 查「填的那個反證條件是不是真的可觀察」 |
| 查「規則有沒有兩個版本」 | 查「規則本身對不對」 |

**右欄那些屬於人的工作，而且刻意不機械化**——
一支會對正確文本報警的感測器，會教會你忽略它，那比沒有感測器更糟。

## 3. 核心概念，四個

<p align="center">
  <img src="docs/fig2_workflow.svg" alt="工作流：證據鏈、誰在看、每一輪的迴圈" width="100%">
</p>


### 3.1 證據鏈有環，而不是「有沒有引用」

一句帶數字的話，從想法到落地要經過七個環節。
**每個環節都可能斷，而斷掉的方式不一樣。**

| 環 | 問題 | 能不能機械化 |
|---|---|---|
| ① 定位 | 該引哪一段？ | ❌ |
| ② **存在** | **那段話在不在原文裡？** | ✅ **零成本** |
| ③ 欄位 | 必填欄位填了嗎？ | ✅ |
| ④ 一致 | 各處說法一致嗎？ | ✅ |
| ⑤ 真偽 | 這篇文獻真的存在嗎？ | ✅ 需外部查證 |
| ⑥ 支持 | 那段話撐得起這句話嗎？ | ❌ **人的工作** |
| ⑦ 外推 | 從那個樣本能推到這裡嗎？ | ❌ **人的工作** |

**②是整套設計的支點**：把「有沒有人真的看過原文」變成一個可以用字串比對回答的事實。

### 3.2 兩本台帳，管兩件不同的事

| | 猜想台帳 | 主張台帳 |
|---|---|---|
| 管什麼 | **文獻層**：這個想法站不站得住 | **句子層**：這句話靠哪一段 |
| 核心欄位 | **反證條件**、最強競爭解釋 | **原句錨點**、頁碼 |
| 失效模式 | 想法變成不可證偽的世界觀 | 數字被憑印象重建 |

### 3.3 失效有「家族」，事故會過去而家族會重演

**記錄單一事故沒有用**，因為下一次不會長得一樣。
要記的是**機制**——見 `governance/Incident_Log.md` §2。

### 3.4 人是唯一的裁決者

⚠️ **這不是保守，是實測結論。**
在兩個先行專案中，**使用者是全系統新型錯誤攔截率最高的一層**，
且其最有效的攔截方式不是「發現 AI 答錯」，而是**提供一份 AI 沒有的外部資料**。

**→ 任何把使用者移出迴路的提案，都要先回答「誰來接這一層」。**

## 4. 這套框架來自哪裡

**兩個實際運行的專案，合計四十餘起登錄事故。**
框架中每一支感測器、每一條硬性規則，都附有觸發它的個案。

⛔ **沒有個案的規則不會被寫進來**——
本框架自己就有一條「無實測個案不建感測器」的規則。

⚠️ **但那條規則有一個例外，而它就是本框架存在的理由：**
`governance/Incident_Log.md` 中標為 `[繼承]`、`[框架自身]` 或 `[預測]` 的失效家族，
**在你的專案裡尚未發生。** 它們列在那裡是為了誠實，不是為了生效——
**你可以據此設防，但不要據此宣稱自己已經免疫。**
