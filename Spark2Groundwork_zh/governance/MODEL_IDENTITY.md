> **可執行形式見 `RULES.md` R-09。本檔定義目前的來源與延續規則，並保留原實驗脈絡。**

## 2. 可用來源，而非平台名稱

不同host可能提供狀態欄、切換事件或完全不提供。先看實際可讀資訊，不假設某平台每輪都有欄位。當下可讀欄位如實記錄；沒有欄位不否定使用者先前已提供的來源。單一正向個案不能保證所有host與版本的行為。

## 3. 規則

### 3.1 型號與來源分開

可讀環境值逐字轉錄；讀不到時，使用者當下口述或介面截圖可作有來源的確認。只知家族／協作稱呼時如實保留，完整版本未知；不得補造版本，不以文風、附件內容或舊封包推論目前身份。記錄稱呼、型號、來源、適用會話與最後確認事件，職務另列。介面／使用者報告不等於後端驗證。

### 3.2 同一會話的延續

一次確認後，沒有切換或新衝突就延續；不因多輪未見model欄位而撤銷、重問或每輪重貼檔頭。摘要可保存來源與本會話範圍；若連來源記錄都不可見，才回到未知。新會話／新實例不直接繼承舊模型確認。更換型號不抹除作者參與，不能因此獨立覆核自己的舊作。

### 3.3 任務資格與衝突

使用者或UI與可讀環境有真實差異時，並列來源，不能冒稱已一致或任選一個當後端真相。只有指定型號關係到本次資格／授權時，釐清後才執行該動作；普通研究與討論可以繼續。完全未知同樣不阻普通工作，不強制重問使用者。

### 3.4 交接的最小相容格式

只在協作／交接紀錄保存歸屬，不要求所有研究正文有模型檔頭。掃描限既有 `attribution_globs`（預設 `handoffs/*.md`）；沒有新增研究目錄或擴大掃描的承諾。

三個欄位各自一行，置於檔頭前15行；不要放進示例程式碼區塊：

```text
[Model: Sol]
[Model source: user]
[Model status: reported]
```

| source / status | Model值與意義 |
|---|---|
| environment / read | 如實讀取的型號／部分名稱；不推導完整版本 |
| user / reported | 使用者明示的型號／部分名稱 |
| ui / reported | 使用者提供的介面上可見名稱 |
| unknown / unknown | `unknown`，沒有可用確認 |
| conflict / conflict | `unknown`，另以文字並列不一致來源 |

來源／狀態值固定如表，型號沒有白名單。平台名不能充當型號。相同欄位有不同值、缺半組欄位或不相容狀態會被拒絕；如實宣告未知／衝突會提醒，但不等於文件不合格或普通工作必須停止。另以文字記會話範圍與最後確認事件（例如「本會話使用者剛提供截圖；完整版本未知」），不猜時間。

舊格式 `[Model: claude-opus-5]` 或既有作者欄仍可讀；帶數字僅是舊格式相容判準，不能認證身份，會提示未記來源。舊「無法讀取」宣告可讀且不要求重問。沒有來源的無版本名字應補實際來源；不能把任意文字加數字當驗證。感測器只能查記錄一致性，無法驗證使用者確實說過或後端是誰。

### 3.5 Git檢查點

檢查點名稱可用已知稱呼或未知；來源留在協作紀錄，不編造版本。此條不授予commit、tag或發布權限，沿原授權與既有工具契約。

`--mode ai --model` 接受已知稱呼（包括 `claude`、`gemini`、`gpt`、`Sol`）或 `unknown`；拒絕平台名、空值／佔位字、控制字元、`[`／`]`／`|` 分隔符及只有標點的值。這只檢查稱呼結構，不認證後端型號。實際來源／狀態仍留在既有交接紀錄（§3.4），不另加 checkpoint 來源旗標。AI 檢查點不移動真人 `reviewed` 標籤。

人類感測器輸出將歷史未載來源計數成一則摘要；它們不是新增錯誤，不需逐份追補。`sensor_model_attribution.py --json` 保留所有路徑與逐筆 findings。每次執行仍全掃設定範圍；新欄位缺漏／矛盾及未知／衝突提醒繼續可見。

### 3.6 切換事件與截斷

切換是重新確認的觸發；更新目前紀錄並保留舊作者歸屬。欄位暫時不出現不是切換證據。不能用平台名掩蓋失去來源的情況。

#### 3.6.1 歷史個案的保留

下列為原協定已有的個案記錄，並非本次重跑或所有平台的保證。

**實證個案。** 先行專案一份 git 審計交接封包的作者欄為 `[Model: Antigravity]`。
使用者查明實為 **3.1 Pro**，並取得該模型的自檢說明：當時 Antigravity 工作區對話過長，
先前上下文已被系統截斷（Truncated），**`<USER_SETTINGS_CHANGE>` 標記不在可見範圍內**；
輸出 `Antigravity` 是退回系統提示中的通用名稱。該系統提示只載明
「You are Gemini, a large language model built by Google」與「designed by the Google Deepmind team」，
**不含具體版本號**。

#### 3.6.2 個案的適用範圍

事件可能在截斷後不可見；能延續的是仍可見且適用本會話的來源記錄。不能從這個個案推導所有平台恆有／恆無訊號。

#### 3.6.3 不可省略的界線

未知就記未知；平台不是模型；使用者確認可以補回已知名稱，且應延續來源。只在資格必要或真實衝突待處理時詢問，不設逐輪補填義務。

### 3.7 欄位位置改變

在實際可讀系統內容的另一處找到逐字值，可以記錄該位置；找不到依3.1接受有來源的使用者確認或記未知。不要虛稱讀到了不存在的欄位。

## 4. 機械防線的邊界

`scripts/harness/sensor_model_attribution.py`只檢查設定範圍內的檔頭，不讀後端、不保存會話、不驗證截圖。可在既有交接保留確認摘要；不必為每輪建立新的身分軌跡表。

## 5. 本協定不宣稱的事

不保證模型永不忘記、不把檔頭當身份認證，也不保證提示一經修改就已載入所有既有對話。使用者可保留自訂規則，依框架README預覽更新並重新載入。
