# 猜想台帳規格（Conjecture Ledger Spec）

**文件層級：T1 — 規格類。⚠️ 本檔隨框架升級整包替換。**

> 🔴 **本檔定義猜想的狀態與門檻；`ledgers/Conjecture_Ledger.md` 放的是猜想本身。**
> **⚠️ 為什麼分開：憲章 §6.4（⛔ 本處不重述）。**

---

## 0. 使用方法

### 0.1 六種狀態

| 狀態 | 意義 | 可否作為前提 |
|---|---|---|
| 🔵 **猜想** | 尚未查證，可證偽性尚未確認 | ❌ 不可 |
| 🟡 **已可證偽** | 反證條件與競爭假說皆已填寫且成立 | ❌ 不可作前提，但可作為研究假設 |
| 🟢 **文獻支持** | 已有文獻支持，且該文獻確實說了這件事 | ✅ 可，須附文獻與位置 |
| 🔴 **已被推翻** | 現有證據與之相反 | ❌ 不可。**保留紀錄，不得刪除** |
| ⚫ **不可證偽（已除役）** | 經切分嘗試後仍無法產出可觀察的反證條件 | ❌ 不可。**保留紀錄，不得刪除** |
| 🟤 **休眠** | 連續多輪未被引用，且非當前工作範圍 | ❌ 不可作前提。**紀錄完整保留** |

### 0.1a 🟤 休眠 ≠ ⚫ 除役

| | 除役 ⚫ | 休眠 🟤 |
|---|---|---|
| 宣稱了什麼 | 原則上不可證偽 | **什麼都沒宣稱** |
| 登錄成本 | 四項（§0.1b） | 一行：休眠日期 ＋ **喚醒條件** |
| 可否回復 | 需重新登錄新編號 | 改狀態即可 |

⛔ **休眠須寫「喚醒條件」，不得只寫日期。** 沒有喚醒條件的休眠等於靜默刪除。
⛔ **感測器不自動降級。** 自動降級會讓「沒有人提起它」變成「它不重要」，**而那兩件事不同**。

⚠️ **為什麼需要休眠：** 在發想階段，猜想的產生速率遠高於除役速率——
**這是階段的本質，不是紀律問題。** 若唯一的出路是成本高昂的除役，
**「什麼都不做」的成本是零，所以它會是預設選項。**

### 0.1b ⚫ 除役的門檻

「不可證偽」有兩種，**只有一種該被除役**：

| 型態 | 描述 | 處置 |
|---|---|---|
| **(a) 原則上不可證偽** | 無論怎麼切分都得不到會使它為假的結果 | ⚫ **除役** |
| **(b) 當前表述不可證偽** | 主張有內容，只是寫得太寬；切分後可檢驗 | 🔵 **保留**，列為待切分 |

⚠️ **除役前必須先做過至少一次切分嘗試並留下紀錄。**
**若允許「反證條件填不出來 → 直接刪」，等於獎勵不去嘗試——
填欄位比切分主張容易，而刪除比兩者都容易。**

### 0.2 每筆猜想的必填欄位

```
### C-NN ｜ <狀態> ｜ <歸屬>

**「歸屬」＝ 這條猜想屬於哪一條研究線或哪一個對象群。**
單線專案填「主線」即可；多線專案填線名。⚠️ **取值一經使用即固定，不得中途改名。**

**表述：**      一句話，可獨立閱讀，不依賴上下文
**來源：**      這個猜想從哪裡來
**反證條件：**  哪一種可觀察的結果會推翻它。填不出來時填「—」
**反證條件裁決：** `未裁決` ／ `已裁決` ——⛔ 只有人可以改成 `已裁決`
**填不出來的理由：** **選填。** 反證條件填「—」時，在這裡寫為什麼填不出來
　　　　　　　　⚠️ 填了它，感測器會改報 `FALSIFICATION_DECLARED_UNFALSIFIABLE`
　　　　　　　　而不是「反證條件為空」——**因為那是兩種不同的狀態**
　　　　　　　　⚠️ **與根目錄 `第一個想法.md` 第 3 條同一措辭。**
　　　　　　　　⛔ 欄位名同樣是規則，同樣只能有一個定義處（憲章 §3.2）
**最強競爭解釋：** 具體指名，⛔ 不得寫「另有學者持不同看法」
**競爭解釋的不同預測：** 競爭解釋預測什麼，與本猜想何處分歧
**依據：**      🟢 須指名文獻與位置；🔴 須指名推翻依據
**紀錄：**      建立日期與狀態變更軌跡
```

### 0.3 六條硬性規則

1. 反證條件必須是**可觀察的**。**填不出來的猜想不是研究假設，是世界觀。**
   🔴 **填「—」不會比亂填更糟，這是刻意設計的。**
   ⚠️ **原因（實測發現）：** 若感測器只在「欄位為空」時告警，
   **誠實留白會亮黃燈，而編一句讀起來合格的假反證條件不會**——
   **沒有任何人或感測器分得出那是裝飾品。獎懲方向是反的。**
   → **修正：告警的條件不是「欄位空」，而是「尚未經人裁決」。**
   **填了字不會讓警示消失，只有人按下「已裁決」才會。**
   ⛔ **AI 不得自行把 `反證條件裁決` 改成 `已裁決`。**
2. 競爭解釋必須具體到能推出**不同的可觀察結果**。**裝飾性的競爭假說比沒有更糟。**
3. 🔴 與 ⚫ **不得刪除**——**刪除紀錄會使同一個主張在數輪後被重新提出，
   而沒有人知道它已經被檢驗過。**
4. 狀態變更須有**可獨立複核**的依據。
5. ⛔ **AI 不得直接寫入本台帳**，須以決策請求回報。
6. 猜想表述**一經登錄即凍結**；需修改時登錄新編號並註明取代關係。

### 0.4 編號命名空間（⛔ 不得混用）

| 前綴 | 用途 |
|---|---|
| `C-NN` | **猜想**（兩位數） |
| `M-NN` | **主張**（主張台帳） |
| `W-n` | 工作項目 |
| `R-n` | 待裁決事項 |

⚠️ **工作項一律加前綴。** 若寫成 `C-1`，感測器會**靜默地**把它當成猜想 C-01 的引用而放行。
