開始前，先檢查專案

你不需要輸入終端機命令。先解壓縮完整的中文版資料夾，再雙擊根目錄的 檢查專案.bat（Windows）或檢查專案.command（Mac）。結果視窗只需閱讀，最後按鍵關閉。

缺少工具時

  1. Python：到官方下載頁取得適用系統的安裝程式，按安裝畫面完成。Mac使用官方pkg；Windows請在Windows下載頁選擇支援你系統的穩定版，於該版下載清單選Windows installer (64-bit)，再按Install Now。此路徑使用完整安裝程式；只下載安裝管理員而未裝Python，仍不算就緒。無須手改PATH；完成後重新雙擊檢查。
  2. Git：Windows使用官方安裝程式。Mac可從Apple下載頁登入並下載適用系統的Command Line Tools for Xcode，開啟dmg/pkg安裝；不必安裝整套Xcode，也不需貼命令。

Mac首次開啟被擋

先確認檔案來源。依Apple安全開啟說明處理該檔案的提示；不要整批關閉安全檢查。若沒有可用的開啟選項，或顯示無執行權限，保留訊息並回報，勿把它當作檢查成功。這類首次下载問題仍需原生Mac驗收，不能由Windows代證。

看懂結果

  • PASS／0：本次機械檢查通過，不代表研究主張已獲證實。
  • FAIL／1：有待處理的檢查發現。
  • INCOMPLETE／2：缺工具、缺檔或檢查未完成，不能當作通過。把完整畫面交給AI；新下載尚無快照時依SETUP處理。

如果AI只在遠端或虛擬機執行，不能拿那裡的版本當作你的電腦環境。請在自己的電腦雙擊。即使工具未就緒，你仍可填寫PROJECT.md與第一個想法.md，不必先解決全部工具問題。

檢查不安裝程式、不初始化Git、不改研究文件。既有檢查會更新scripts/harness/harness_status.json。若檢查逾時，子檢查可能仍在跑，請先回報而不要連按。此入口只處理環境及專案檢查；快照、查看變更與更新操作請依SETUP。
