# v2 升級準備（目前不遷移）

v2 尚在開發；目前沒有轉換程式，也不保證所有 v1 自訂格式能自動轉換。
你可以繼續使用本版，毋須先改資料夾名稱或刪除任何研究資料。

1. 在專案資料夾外，完整複製一份備份，包含隱藏檔、文獻原件、提取物、台帳、研究稿、自訂規則、交接紀錄及 Git 歷史（若有）。快照可能排除部分檔案，不能取代完整備份。
2. 請 AI 記錄使用語言、五個框架資料夾的版本標記、已改過的框架文件、額外工具及自訂資料位置。混版照實記錄，不先改標記冒充已升級。盤點可存於備份旁，不必為此變更台帳。
3. 打開備份中的代表性稿件與文獻，確認可閱讀；保留原專案繼續工作。
4. 等 v2 接近完成，依正式遷移指引，讓 AI 協助在另一份副本搬移、比對與驗證，再由你決定切換。現在不做預先轉換。

v2 預計分為 `agents framework/`（框架）、`agents data/`（專案自有協作資料）及 `research data/`（專案自有研究資料），根目錄保留簡短入口。初始化選一種語言，後續更新核心與所選語言；不自動翻譯研究稿。最終細節以 v2 正式文件為準。

從 v1.4.4 遷移不要求先安裝 v1.4.5。更新程式不應覆寫研究原件；來源定位、查證與人類接受仍是不同工作，檢查通過不保證研究正確。
