# corpus/ ── 放你的論文原文

**把你要引用的 PDF 全部放進這個資料夾。**

一篇一個檔，檔名建議寫成「第一作者_年份_關鍵詞.pdf」，例如：

```
Chen_2023_working_memory.pdf
Lin_2021_bilingual_advantage.pdf
```

**為什麼要放進來：** 框架會檢查「你引用的那句話，到底在不在原文裡」。
原文不在專案裡，這件事就查不了——**而查不了不等於沒問題。**

---

## 這個資料夾裡還有一份 `書目總表.docx`

**那是本專案的引用格式權威。**
用 Zotero 或 EndNote 匯出書目，貼進去，之後所有引用格式以那份為準。
